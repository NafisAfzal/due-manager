# Due Manager

A simple task manager made with HTML, CSS, and JavaScript.

## About

Due Manager keeps a short list of active tasks in the browser. You can
add tasks, mark important ones with a star, search, filter, and edit
titles inline. There is no account and no server. Tasks are stored
locally in the browser using localStorage.

## Features

- Add tasks
- Star important tasks
- Search tasks
- Starred-only filter
- Newest-first sorting
- Inline title editing
- Complete and delete tasks
- Responsive layout
- Keyboard accessible controls

## Run Locally

1. Download or clone the repository.
2. Open index.html in a browser.
3. Add a task and press Enter.

No build step is needed. You can also serve the folder with any static
file server.
